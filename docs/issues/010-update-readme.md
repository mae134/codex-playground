# Issue010

## Title

READMEの更新

## Goal

現在の開発フローおよびドキュメント構成に合わせてREADMEを最新化する。

## Scope

- ルート `README.md` の更新
- `docs/issues/README.md` の更新
- `docs/prompts/README.md` の更新
- Playbookとの整合性確認
- 古い説明・リンクの修正

## Out of Scope

- Playbookの変更
- AGENTS.mdの変更
- Prompt Templateの変更
- 開発フローの変更

## Constraints

- ドキュメントのみ変更する
- 現在のPlaybookに合わせる
- 内容を追加しすぎず、必要な更新に留める

## Acceptance Criteria

- READMEが現在の運用内容を反映している
- 古い説明・リンクが残っていない
- 各README間で説明に矛盾がない
- 初めて読む人でも構成が理解できる

## Deliverables

- 更新した `README.md`
- 更新した `docs/issues/README.md`
- 更新した `docs/prompts/README.md`
